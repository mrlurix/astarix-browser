FAQ & Troubleshooting

Short answers to common questions.

Where is my data stored?

History, bookmarks, extensions and settings stay on your machine in the app profile. Nothing is uploaded anywhere — there is no account and no telemetry.

Windows shows a SmartScreen warning?

The portable build is unsigned, so SmartScreen may warn on first run.

This is expected for unsigned software. Click More info, then Run anyway — or build from source if you prefer.

Can I install extensions from the Chrome Web Store?

No. Only unpacked extension folders can be loaded (⋮ → Extensions → Load Extension), and each manifest is screened for dangerous permissions first.

FTP support?

No. Astarix supports http and https only — anything else in the address bar becomes a search.

Developer tools?

Yes. Press F12 (or Ctrl+Shift+I, or menu → Developer Tools) to inspect the current page.

Linux or macOS builds?

Only Windows x64 portable builds are published for now.

How do I reset everything?

Open ⚙ Settings → Reset All Settings for the options. For a completely fresh start, quit the browser and delete the profile folder (%APPDATA%\Astarix Browser).
