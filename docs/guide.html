ASTARIX Download & Install

From download to browsing in about a minute.

Requirements

  • Windows 10 or 11, x64
  • About 250 MB of free disk space
  • No administrator rights needed

Download

Grab the latest portable build from the Releases page:

AssetWhat it is
Astarix-Browser-Portable.exeThe browser, single file (~90 MB)

Run portable

  1. Download Astarix-Browser-Portable.exe
  2. Double-click it — no installation, no setup wizard
  3. A new tab opens. Type a URL or a search in the address bar and browse
Portable means the program is one file. Your profile (history, bookmarks, settings) is stored separately on your machine, so replacing the exe never deletes your data.

Build from source

Requirements: Node.js 18+ and npm.

git clone https://github.com/mrlurix/astarix-browser.git
cd astarix-browser
npm install
npm start        # run in development mode
npm run build    # obfuscate + package the portable exe
The packaged exe lands in build-staging/dist/Astarix-Browser-Portable.exe. If npm install skips Electron's postinstall step, run node install.js once inside node_modules/electron to fetch the binary.

Update

  1. Download the newer Astarix-Browser-Portable.exe from Releases
  2. Replace the old file. Your profile and settings are kept

Uninstall

del Astarix-Browser-Portable.exe

To also wipe your profile (history, bookmarks, settings), delete the data folder:

rmdir /s "%APPDATA%\Astarix Browser"
